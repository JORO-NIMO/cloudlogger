CloudLogger Platform Documentation

Serverless Log-As-A-Service Micro-SaaS Engine

Cloudflare Edge Serverless Architecture

CloudLogger runs 100% within the Cloudflare serverless ecosystem without traditional servers, Docker containers, or VPC management:

  • Cloudflare Workers: Executes edge API routing, schema validation, CORS negotiation, and cryptographic Web Crypto HMAC hashing at under 10ms execution times.
  • Cloudflare D1 SQLite Database: Provides indexed, ACID-compliant persistence for multi-tenant accounts, connected sites, and high-volume system telemetry.
  • Cloudflare Pages: Serves the responsive analytics dashboard directly from Cloudflare's global CDN.

Cryptographic Edge Privacy & PII Redaction

Regulatory frameworks (GDPR, CCPA, HIPAA) prohibit storing raw customer emails and IP addresses in plaintext. CloudLogger intercepts all incoming payloads at the edge:

HMAC_SHA256(body.actor, env.HASHING_SECRET) → actor_hash
HMAC_SHA256(body.metadata.ip_address, env.HASHING_SECRET) → ip_hash

The raw plaintext values of actor and ip_address are completely stripped out before database insertion. Only deterministic, salted cryptographic hashes are saved to D1.

Core REST API Endpoints

POST /v1/auth/register

Registers a new account. Body: { email, password, site_name }. Returns personal API key cl_live_... and default site.

POST /v1/auth/login

Authenticates email & password. Returns active session token and all connected sites.

POST /v1/logs

Ingests telemetry events. Requires Authorization: Bearer <API_KEY>. Body must contain project_id, module_name, action, status.

GET /v1/logs?project_id=:id

Retrieves latest 200 telemetry events for a specific connected site.

POST /v1/webhooks/whop

Automated Whop payment lifecycle webhook receiver (payment.succeeded, membership.went_valid).
